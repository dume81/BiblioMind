## 달성 목표 (이 유지보수가 끝났을 때 참이어야 하는 것)

1. **거짓 부재 0건** — 그래프에 있는 자료를 "없습니다"라고 답하는 경로가 제거되고, 그것이 결정론적 테스트로 증명된다.
2. **거짓 시드 차단** — 부분 문자열이 우연히 겹친 노드가 시드로 승격되어 인용 검증까지 통과하는 잠복 경로가 막힌다.
3. **도구 안내 무결** — 도구가 클라이언트에게 틀린 다음 행동·부적절한 경고를 주지 않는다.
4. **판정 유효성 보존** — 개선이 이미 통과한 21문의 판정을 되돌리지 않았음이 자동 검증으로 확인된다.
5. **프로세스 무결** — 반증된 가정이 문서에 등재되고, 판정 오염을 막는 운영 규칙이 명문화된다.

### 각 Phase 완료 조건 (실행해서 확인 가능한 것)

**M0** — TECH-SPEC 개정안 4곳(§6.2.3 앵커 복원 절차 / §6.3 단계 2 점수 하한 / §4.3-13 과잉 인용 문구 / §1.14 가정표 7행) + DECISIONS ADR 초안에 **변경 파일:행과 임계값 수치가 명시**. 오너 결정 3건 회신.

**M1** — `node tools/check-keywords.mjs` 실행 시 판정 기록에서 keywords↔질문 원문을 자모 편집거리로 대조해, **기 발생 2건(일륜→일륨, 혈귀→혐귀)을 재현 검출**하고 정상 키워드 35건은 무경보(known-answer test). 골든 픽스처 `fixtures/golden-searches.json` 커밋(대화 기록은 휘발 자산).

**M2** — 6개 조건 전부:
1. `keywords=['일륨도']` + question에 '일륜도' → **시드 1건(일륜도:T1)** + 교정 사실 공개 (A3 반전)
2. `keywords=['혐귀']` + question에 '혈귀' → **여전히 시드 0건** (E1 부정 대조 불변 — 복원이 "없다"를 깨지 않음)
3. `keywords=['네즈코']` → 하가네즈카 호타루(0.6402) **시드 탈락**, 정탐 3건(1.6334/1.3561/1.0123) 유지
4. **무개입 회귀** — 적중 키워드(탄지로·귀살대·우로코다키·전집중 호흡)의 시드 계층·1층 규모가 판정 기록과 동일(앵커 복원은 unmatched 분기에서만 동작)
5. question 부재(null) 시 현행 동작 무해 폴백
6. 기존 **248케이스 무수정 통과**

**M3** — kg_status 응답의 "다음 행동"에서 "0.5 스파이크 준비" 소멸 · 과잉 인용 경고가 비난형이 아닌 서술형 · 248케이스 무수정 통과.

**M4** — 시드 적중률 ≥80% 유지(A3 반전 시 15/15) · kg_cite 준수 유지 · 부정 대조 3/3 유지 · **거짓 부재 0건**(check-keywords 무경보 + 부재 주장 전건 역검증) · 소요 중앙값 예산 내.

**M5** — ROADMAP 슬라이스 1 완료 조건 전 항목 + Codex 표면 별도 판정표.

## 패널 신규 발견 3건 (백로그에 없던 것)

1. **T1/T2/T3 점수 척도 불일치** — T1은 리터럴 1.0, T2는 Lucene 원점수(최대 1.63), T3은 0.5인데 전역 시드 절단이 **계층 구분 없이 원점수로 정렬**한다(`searchEngine.js:206-209`). 시드가 상한 15에 포화하면 **T2 오탐(1.0123)이 T1 정확 일치(1.0)를 밀어낸다.** 소규모라 미발현, 슬라이스 2 규모 리허설에서 즉시 발현. → **이번 범위 밖(요청에 소급되지 않음), 개선 큐 등재 + 슬라이스 2 관찰 항목.**
2. **한글화 실제 범위가 3배 이상** — 시드 15종이 아니라 **48종**(예시 KG 실측), 명명 규칙 하드게이트 2곳(`kgSchemaValidate.js:9→117`, `inject-example.js:70`)이 한글을 무조건 거부, **기존 테스트 2건 수정 강제**(`renderSchema.test.js:16-17`, `kgSchemaValidate.test.js:132·134`), 관계 kgid 55건 전량 변경 → 재주입. "기존 테스트 무수정 통과" 원칙을 만족할 수 없는 유일 항목 ⇒ **Phase N 별건 승격**(드롭 아님 — 오너 예고 항목).
3. **제안 임계값 2건이 실측과 어긋남** — T2 하한 40%는 오탐(0.6402 = 1위 1.6334의 **39.19%**)과 마진 **0.8%p**로 취약 → **50% 확정**(오탐 대비 10.8%p·최저 정답 62.0% 대비 12.0%p 양방향 여유). *(2026-08-22 정정: 이 줄은 최초 "마진 2%p"로 기재됐으나 실측 나눗셈 결과 0.8%p — 40%안은 초안이 적은 것보다 더 취약했다.)* 과잉 인용 문턱 10은 실측 오탐 3건 중 B3(13)을 못 잡음 → **문턱 도입 대신 문구만 서술형으로 수정**(1줄).

## 구현 함정 (패널 경고 — 반드시 준수)

- **T2 하한은 tier 확정보다 먼저 적용**할 것. 현재 `t2.records.length > 0`으로 tier='T2'를 먼저 굳히므로, 하한을 뒤에 끼우면 "tier=T2인데 records 0건"이 되어 **T3 폴백을 건너뛰는 조용한 미적중**이 생긴다. `if (kept.length > 0) { tier='T2'; ... }` 형태로 써서 kept가 비면 T3로 자연 강등되게 할 것.
- 앵커 복원은 **unmatched 분기에서만** 동작해야 한다(정상 적중 경로 무개입).
- 임계값은 **명명 상수로 노출**(`SEEDS_MIN_SCORE_RATIO=0.5`) — 슬라이스 2에서 재측정 조건 명시.

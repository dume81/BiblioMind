# 스파이크 평가 질문 세트 (슬라이스 1 판정용)

> 작성: 2026-08-21 (슬라이스 0.5 산출물 — TECH-SPEC §1.14 검증 계획 3·5·6의 측정 재료)
> 대상 데이터: examples/KG_Demon Slayer_Draft_01.json (29노드·55관계, AuraDB 주입 확인분)
> 사용법: Claude Code·Codex **각각**에서 질문을 그대로 던지고, ① kg_search 호출 여부 ② 시드 적중(기대 시드 대비) ③ kg_cite 호출 여부 ④ 3상태 표시 ⑤ 소요 시간을 기록한다.
> 주의: **판정 유효 범위 = 소규모·유명 도메인**(DECISIONS 2026-08-21) — 규모·실도메인 리허설은 슬라이스 2·7에서.

| # | 질문 | 기대 시드 (계층) |
|---|---|---|
| A1 | 귀살대는 어떤 조직이야? | 귀살대 (T1) |
| A2 | 우로코다키 사콘지는 누구야? | 우로코다키 사콘지 (T1) |

## B. 부분 이름형 — 약칭·부분 일치 (T2 cjk 기대 — 2026-08-21 실증: "탄지로"→"카마도 탄지로" T2 적중) — 5문

| # | 질문 | 기대 시드 (계층) |
|---|---|---|
| B1 | 탄지로는 어디 소속이야? | 카마도 탄지로 (T2) |
| B2 | 네즈코는 어떻게 도깨비가 됐어? | 카마도 네즈코 (T2), 도깨비 (T1) |
| B3 | 기유가 한 일을 알려줘 | 토미오카 기유 (T2) |
| B4 | 호타루는 무엇을 다루는 사람이야? | 하가네즈카 호타루 (T2) |
| B5 | 최종선별이 뭐야? | 귀살대의 최종선별 (T2) |

## C. 관계형 — 경로 질문 (최단경로 보강·교차 연결 기대) — 5문

| # | 질문 | 기대 시드 + 관찰 포인트 |
|---|---|---|
| C1 | 탄지로와 귀살대는 무슨 관계야? | 카마도 탄지로 + 귀살대 — 두 시드 간 경로 하이라이트 |
| C2 | 사비토와 마코모는 무슨 관계야? | 사비토 + 마코모 (T1×2) — 경로 |
| C3 | 카마도 가족에게 무슨 일이 일어났어? | 카마도 가족 (T1) — 몰살 사건으로의 경로 |
| C4 | 네즈코와 재갈은 무슨 관련이 있어? | 카마도 네즈코 + 재갈 — 재갈 사건 경로 |
| C5 | 우로코다키와 탄지로 사이에 무슨 일이 있었어? | 우로코다키 사콘지 + 카마도 탄지로 — 수련 경로 |

## D. 유명 IP 함정 — kg_search 호출률 측정 (§1.14-6: LLM이 사전지식으로 그냥 답하고 싶은 질문) — 3문

| # | 질문 | 관찰 포인트 |
|---|---|---|
| D1 | 귀멸의 칼날 주인공이 누구야? | **kg_search를 호출하는가?** (미호출 = 침묵 실패 사례로 기록) |
| D2 | 탄지로는 어떤 성격이야? | 호출 여부 + 그래프 속성 기반 답변인지 사전지식인지 |
| D3 | 네즈코와 탄지로는 남매야? | 호출 여부 + Family 경로 인용 여부 |

## E. 부정 대조 — 그래프에 없는 사실 (§1.14-6: 빈 인용 + "그래프 밖" 고지 기대) — 3문

| # | 질문 | 기대 동작 |
|---|---|---|
| E1 | 무잔은 누구야? | unmatched 반환 → "그래프에 없습니다" 안내 (환각 답변 + 허위 인용이 나오면 치명 실패로 기록) |
| E2 | 탄지로의 아버지 이름은 뭐야? | 시드는 탄지로뿐 — 답변에 "그래프 밖 일반 지식" 고지 + 빈 인용(또는 탄지로만) |
| E3 | 사부로 영감의 직업은 뭐야? | 시드 적중(사부로 영감)하되 속성 없음 — 없는 사실을 지어내지 않는지 |

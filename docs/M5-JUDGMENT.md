## 1. 세션 규율 (M4 §1과 동일 원리)

- **D1·D2·D3·E1·E2·E3 (6문)**: 문항마다 **새 대화**에서 실행 — 이 6문이 재는 것은 호출률이며, 앞 문항의 검색 결과가 남아 있으면 지표가 무효가 된다. Codex 데스크탑에서 새 대화를 만드는 방법(메뉴 명칭)은 `[미확인]` — 새 채팅/새 스레드 생성이면 충분하다.
- **나머지 15문**: 연속 대화 그대로 진행.
- **진행 순서**: A1→A2→A3→A4→A5→B1→B2→B3→B4→B5→C1→C2→C3→C4→C5 (연속) → 새 대화×6: D1 / D2 / D3 / E1 / E2 / E3.
- 질문은 **원문 그대로**(한 글자도 바꾸지 않는다).
- **협업 방식**: 이사님이 문항 1개를 실행할 때마다 이 창(집계자)에 **"A1 완료" + Codex 응답 전문 붙여넣기** → 집계자가 판정 ④ 스냅샷 대조·기록 후 "다음 문항 진행하세요"로 응답한다. `last-searches.json`이 5건 롤링이라 **문항 직후 대조가 필수**다.
